## Решаем Metric Uncapacitated Facility Location Problem

### Требования

```
python3
```

### Как запустить

```
pip install -r requirements.txt
python3 main.py
```

В main.py будет создана 1 задача, решена приблизительно и точно. В ноутубке выстроен пайплайн для генерации большного числа задач, создания графиков.
